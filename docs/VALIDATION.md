## 原安装布局实机验证

- OBS Tools 菜单首次启动普通启动器，经 Windows 授权建立管理员后台。
- 本机 H.264/AAC 输出与伴侣预览接入。
- 闲置伴侣重启后，严格接管其恢复的素材新 UUID，素材总数没有增加。
- 新 owner 下启动、停止、再启动，并确认最后 OBS 本机输出和转发器停止。
- 用户实际点击面板 X 发生在停止状态，面板收起而后台仍保持停止；真实菜单恢复同一个面板和后台，无新 UAC。
- 同一原安装二进制的注册关闭回调另在实际输出中执行，收起及恢复期间输出继续。这不冒充“运行时人工点击 X”的独立记录。
- 停止本机输出时，独立 OBS 录制继续。

原日志、运行 manifest、账号画面、源 UUID 和进程记录只保存在测试机器，未提交到公开仓库。
